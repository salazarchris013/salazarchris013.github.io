Starting Point

CS 360 Inventory Tracker — the original Android application, unmodified, submitted in Mobile Architecture & Programming.

Enhancement One — Software Design & Engineering

Repository pattern & input validation

Pulled database access out of the Activity classes into a dedicated InventoryRepository, and consolidated input validation into a reusable InputValidator, so the code is organized around single responsibilities.

Narrative Source code
Enhancement Two — Algorithms & Data Structures

In-memory model, efficient sort & search

Loaded inventory into an in-memory list of InventoryItem objects instead of querying the database on every interaction, with live sorting and searching kept in sync with storage on every edit.

Narrative Source code
Enhancement Three — Databases

Normalized schema & join-based queries

Replaced a single flat table with related categories, suppliers, and item_transactions tables joined by foreign keys, plus a non-destructive schema upgrade path and CSV import.
